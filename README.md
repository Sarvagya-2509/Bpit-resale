# 🎓 BPIT Resale Platform

A student-focused marketplace designed exclusively for BPIT students to buy and sell academic essentials such as books, calculators, lab coats, drafter, engineering sheets, and more.

This platform helps students save money, reduce waste, and support juniors by reusing academic resources.

---

## 🚀 Features

- 🏠 Modern Home Page with clean UI
- 🔍 Explore page to browse available items
- ❤️ Wishlist functionality to save items
- 💰 Sell page to post items for resale
- 🔐 Login / Signup interface (frontend)

---

## 🎯 Purpose

Many students spend unnecessary money buying new academic tools every semester. This platform solves that problem by creating a centralized marketplace where students can:

- Buy used items at lower prices
- Sell unused items
- Help juniors save money
- Promote reuse and sustainability

---

## 🛠️ Built With

- HTML5
